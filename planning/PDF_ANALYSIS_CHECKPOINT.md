## 1. 확인 방법과 이 문서의 한계

현재까지 다음 작업을 실제로 수행했다.

1. `pdfinfo`로 8개 파일의 전체 PDF 페이지 수를 확인했다.
2. 8개 파일 전체 범위를 레이아웃 보존 텍스트로 추출했다.
3. 목차, 장·절 제목, 핵심 용어의 등장 위치를 확인해 자료별 내용 지도를 작성했다.
4. 그림 중심 강의자료는 대표 페이지의 구조와 도식 유형도 함께 확인했다.
5. 서로 겹치는 주제와 사이트의 어느 페이지에 사용할지 비교했다.

다만 아래 분석은 모든 문장·그림·기출문항을 한 줄씩 교정 완료했다는 뜻이 아니다. 이미지 안에만 들어 있는 작은 주석, 표의 세부 수치, 개별 문제의 선택지까지 전수 검증하는 작업은 최종 콘텐츠 작성 직전에 해당 단원을 다시 대조해야 한다. 확인하지 않은 내용을 읽었다고 표시하지 않기 위해 자료마다 남은 검토 범위를 따로 적었다.
